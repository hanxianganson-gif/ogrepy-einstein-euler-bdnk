# Verification status

Verification date: 2026-08-19.

Environment used: Python 3.12, OGRePy 1.3.1, SymPy 1.14.0.

## Strictly checked

1. Every Python code cell in the original notebook compiles.
2. The formulas for $\mathcal E$, $\mathcal P$, $\mathcal N$, $Q^\mu$,
   $\mathcal J^\mu$, and $T^{\mu\nu}$ match the general first-order
   constitutive ansatz in Eqs. (4)–(6) of arXiv:2009.11388, after matching
   notation.
3. A fresh symbolic execution passed all of the following exact identities:

   - $u_\mu u^\mu=-1$;
   - $\Delta^{\mu\nu}u_\nu=0$;
   - $u_\mu a^\mu=0$;
   - $\sigma^{\mu\nu}=\sigma^{\nu\mu}$;
   - $g_{\mu\nu}\sigma^{\mu\nu}=0$;
   - $u_\mu\sigma^{\mu\nu}=0$;
   - $u_\mu Q^\mu=u_\mu\mathcal J^\mu=0$;
   - $-u_\mu J^\mu=\mathcal N$;
   - $\Delta^\mu{}_{\nu}J^\nu=\mathcal J^\mu$;
   - $u_\mu u_\nu T^{\mu\nu}=\mathcal E$;
   - $\frac13\Delta_{\mu\nu}T^{\mu\nu}=\mathcal P$;
   - $-\Delta^\mu{}_{\alpha}u_\beta T^{\alpha\beta}=Q^\mu$.

4. Setting all first-order transport coefficients to zero recovers the ideal
   current and stress tensor exactly.
5. The exported $Q^\mu$ and $\mathcal J^\mu$ files were corrected to state
   component identities rather than the false equations `0 = component`.
6. The scalar LaTeX writer was corrected so that it writes an actual newline
   instead of the literal characters `\n`.
7. The previously missing BDNK number-conservation and Einstein–BDNK output
   files were regenerated directly from the checked constitutive tensors.

## Not claimed as verified

- The expanded BDNK energy-conservation, number-conservation, and
  Einstein–BDNK component outputs were generated by OGRePy, but were not
  checked term-by-term by hand.
- Causality, stability, strong hyperbolicity, and entropy-production conditions
  for a particular hydrodynamic frame are not encoded or tested.
- Compatibility with OGRePy 2.x has not been tested. The reproducible
  environment therefore pins OGRePy 1.3.1.

## Assessment

The constitutive tensor construction is internally consistent and suitable as
a compact symbolic-computation research output. The repository should not be
presented as a new proof of BDNK well-posedness or as a validated numerical
simulation.
